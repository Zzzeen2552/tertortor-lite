# Berakit ke Hulu: referensi

Channel sendiri (bukan bagian Musafo): kisah asal-usul merek dan pendiri usaha Indonesia. Alur dan engine sama dengan
Musafo (storyline → naskah → Gemini TTS → satu gambar per shot di Google Flow → klip H3 di RunningHub → caption ID + EN,
maks 90 s). Yang beda: gaya gambar dan aturan cerita (skill `/berakit-ke-hulu`).

- `video/`: video acuan (mp4/mov), atau `links.txt` berisi satu link per baris (TikTok, Reels, Shorts).
- `gambar/`: gambar acuan gaya (ilustrasi, palet warna, tekstur). Gambar di sini dipakai sebagai ingredients di Flow.
- Catatan bebas (nada, contoh, larangan) tulis di bawah garis.

Analisis gaya ada di `analysis.md`; blok gaya (`styleAnchor`, `people`, `clipLook`, `clipKeep`) di `brand/brand.json →
berakitkehulu`. Tidak ada fakta, angka, atau tahun yang dikarang; logo merek nyata hanya di shot penutup.
