## Example 9: Brief to batch

User brief (Indonesian narration): "Dia hanya anak pelabuhan yang membawa karung. Malam hari belajar membaca buku tentang kopi. Bertahun-tahun kemudian kapal-kapalnya berlayar ke seluruh dunia."

Beats and shots:
1. Anak pelabuhan → **Pier with sacks** (Example 2).
2. Belajar malam hari → **Self-study under a bulb** (Example 4).
3. Hands on machine as the turning point → **The price tag** (Example 5).
4. Kapal berlayar → **Empire scale** (Example 8), with a time-jump frame of the same harbor in modern day.

Deliver four prompts in the template, each with the full style block, the same boy and young-man sentences reused verbatim, then:
"Flow: Nano Banana 2, 16:9, 2–4 outputs per prompt; use Pro for the title frame. Tip: create a character sheet first and attach it to every prompt."
