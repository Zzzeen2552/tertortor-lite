## Example 8: Brief to batch

User brief (Indonesian): "Menurut Babad, Majapahit berdiri dari hutan maja. Kerajaan itu makmur, tapi kemudian runtuh. Di pesisir, Demak berdiri dengan masjid kayu."

Beats and shots:
1. Hutan maja → **Forest clearing** (legend-leaning, mist, maja tree with a few fruits).
2. Kerajaan makmur → **Gate frame** or **Pool steps** (history, brick detail, Majapahit sentence).
3. Runtuh → **Time-jump**: the same gate ruined and overgrown, no figure.
4. Demak → **Early mosque** (Example 2).

Deliver four prompts in the template, each with the full style block and one era sentence, plus the reminder "menurut Babad…" for narration, then:
"Flow: Nano Banana 2, 16:9, 2–4 outputs per prompt; finish thumbnails with Pro. Tip: generate one plate you love first and use it as the style reference for the rest."
